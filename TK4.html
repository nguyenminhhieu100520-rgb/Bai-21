📑 TK4: Tab View

Hệ thống Tab động với JavaScript

Giới thiệu về Tab View

Tab View là một giao diện người dùng phổ biến giúp tổ chức nội dung thành các phần riêng biệt, cho phép người dùng chuyển đổi giữa các phần mà không cần tải lại trang.

Lợi ích của Tab View:

  • Tiết kiệm không gian: Hiển thị nhiều nội dung trong cùng một vùng
  • Trải nghiệm tốt: Người dùng dễ dàng điều hướng
  • Tổ chức rõ ràng: Phân chia nội dung theo chủ đề
  • Hiệu suất cao: Không cần tải lại trang
💡 Mẹo: Tab View thường được sử dụng trong dashboard, trang sản phẩm, hồ sơ người dùng, và các ứng dụng web phức tạp.

Cách hoạt động

Tab View hoạt động dựa trên 3 thành phần chính:

1. HTML Structure

Cấu trúc gồm các nút tab và nội dung tương ứng với ID duy nhất.

2. CSS Styling

  • Sử dụng display: none để ẩn nội dung
  • Class .active để hiển thị tab được chọn
  • CSS transition tạo hiệu ứng mượt mà

3. JavaScript Logic

Hàm openTab() thực hiện:

  • Ẩn tất cả nội dung tab (xóa class active)
  • Xóa trạng thái active khỏi tất cả nút
  • Hiển thị nội dung tab được chọn
  • Đánh dấu nút được chọn
🎨 Animation: Hiệu ứng fadeIn được thêm vào bằng CSS keyframes, tạo trải nghiệm mượt mà khi chuyển tab.

Ứng dụng thực tế

Tab View được sử dụng rộng rãi trong nhiều loại website và ứng dụng:

📱 E-commerce

  • Mô tả sản phẩm
  • Đánh giá khách hàng
  • Thông số kỹ thuật
  • Chính sách đổi trả

📊 Dashboard Admin

  • Tổng quan thống kê
  • Báo cáo chi tiết
  • Cài đặt hệ thống
  • Quản lý người dùng

👤 Trang Profile

  • Thông tin cá nhân
  • Hoạt động gần đây
  • Cài đặt tài khoản
  • Lịch sử giao dịch
🚀 Mở rộng: Bạn có thể thêm nhiều tab hơn, lưu trạng thái tab vào localStorage, hoặc tích hợp với routing để tạo URL riêng cho mỗi tab.
